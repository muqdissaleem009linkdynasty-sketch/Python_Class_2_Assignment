# Python Class 2 Assignment

# About This Assignment

This repository contains my **Python Class 2 Assignment**.
The assignment helped me practice basic Python programming concepts and improve my problem solving skills.

##  Programs Included

The following Python programs are included in this assignment:

1. **Personal Information Program**
   Displays personal information using Python.

2. **Calculator**
   Performs basic arithmetic calculations.

3. **Marks Calculator**
   Calculates marks and evaluates the result.

4. **Age Category**
   Determines the age category based on the user's age.

5. **Even, Odd & Positivity Checker**
   Checks whether a number is even or odd and whether it is positive or negative.

6. **Shopping Discount Calculator**
   Calculates discounts based on the shopping amount.

7. **Student Eligibility Checker**
   Checks student eligibility according to given conditions.

8. **Personal Profile**
   Displays a personal profile using Python.
